Original MIT chess engine for the make.fun tiny-chess-01 bounty: a complete engine in 4,092 bytes of Python (stdlib only, deterministic) — 0x88 board, negamax alpha-beta with quiescence search, piece-square-table evaluation, MVV-LVA ordering and iterative deepening under a fixed 30,000-node budget. Practice Elo 1,364 (trial-0, official scorer), essentially tied with the sunfish 4K baseline (~1,365) and above the 1,154 floor.

## Run it

```sh
python3 -P -s main.py
```
